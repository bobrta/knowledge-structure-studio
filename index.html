先找關係，再用自己的話解釋。每張圖只處理一個主要問題。

KNOWLEDGE STRUCTURE STUDIO

把內容變成能看懂、能回想的圖。

不是單純畫漂亮圖，而是把一章課程拆成關係、比較、流程與決策。

Learning UI · v2

01 / 先說清楚你要學什麼

貼入一小段內容，先找最適合的學習視圖。

不要一次貼整本書。最理想的是一個章節、一個概念群，或一個你想釐清的問題。

3 steps

一張圖只做三件事

  1. 找結構這些概念是分類、流程、比較，還是因果？
  2. 看關係節點之間為什麼連在一起？
  3. 自己解釋關掉原文後，能不能說回來？

02 / 選擇知識結構

不要所有內容都畫成心智圖。

不同問題需要不同視圖。先選「你要理解的關係」，再選圖。

03 / 視覺學習

概念圖

RELATION

用關係詞連接概念，適合釐清「包含、導致、依賴、影響」。

拖曳移動畫布滾輪縮放點節點看說明

NODE / 節點理解

這個節點在說什麼？

點選圖上的節點，先讀一句說明，再用自己的話重講。

ACTIVE RECALL / 主動回想

先不看原文，回答三件事

  • 它是什麼？
  • 它為什麼重要？
  • 它和哪個概念最容易搞混？

自動保存在這台瀏覽器。

04 / 進階編輯需要精準控制資料時再打開 JSON，不要讓程式碼干擾平常學習。 ⌄

什麼時候需要這裡？

當你要新增節點、改關係、調整比較欄位，或把 AI 產生的結構貼進來時。
